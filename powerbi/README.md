Netflix Content Strategy Analysis (Power BI)

Overview
This project analyzes Netflix’s content dataset to uncover trends in content growth, genre distribution, and regional production patterns.

Tools Used

Power BI
Data Cleaning & Transformation
Exploratory Data Analysis

Key Insights

Content grew rapidly until 2020, followed by a decline in additions
Movies dominate the platform over TV shows
The United States leads in content production
Drama, International Movies, and Comedies are the most common genres

Dashboard Features

KPI cards (Total Titles, Content Distribution)
Time-based trend analysis
Genre and country breakdown
Interactive filters (Type, Year, Genre)
